# Ninja Kits

Hub local para os ZIPs de `F:\NINJA CURSOS`.

## Pastas

- `sources/` — ZIPs brutos (cole aqui os arquivos do disco F:)
- `installed/` — kits descompactados e registrados

## Como usar

1. Copie todos os `.zip` de `F:\NINJA CURSOS` para `ninja-kits/sources/`
   (ou faça upload em `/kits` / anexe na conversa do Cloud Agent)
2. Abra [http://localhost:3000/kits](http://localhost:3000/kits)
3. Clique em **Instalar todos os ZIPs**
4. Abra cada kit no agente (modo **Ninja Kits**)

O kit de edição de vídeo do repositório (`kit-edicao-video/`) já aparece como
`editar-video` sem precisar de ZIP.
