# Visual Design — Marketing Report

The report is a static HTML artifact (single self-contained file, no external assets) styled to feel **dark editorial, Bloomberg-terminal precise, and modern B2B SaaS clean**. Reference aesthetics: Linear changelog, Stripe annual report, Vercel dashboard, Bloomberg Terminal status bar.

## Aesthetic feel

- **Dark mode by default** — operator-friendly, looks premium, reads as "real intelligence product" rather than a marketing brochure.
- **One saturated accent color** (warm amber) used exclusively for deltas, sparkline strokes, KPI tile borders on hover, and section eyebrow pills.
- **Heavy use of mono numerals** with negative letter-spacing — Bloomberg-style ticker feel.
- **Generous whitespace** between sections — never feel cramped.
- **Inline SVG charts only** — no Chart.js, no CDN, no JS dependency. The report opens and renders identically anywhere, even from a saved email attachment.

## Color tokens

```css
:root {
  --bg:         #0a0a0a;
  --surface:    #141414;
  --surface-2:  #1a1a1a;
  --border:     rgba(255, 255, 255, 0.08);
  --border-2:   rgba(255, 255, 255, 0.14);
  --text:       #ededed;
  --text-muted: #8a8a8a;
  --text-dim:   #5a5a5a;

  --brand:      #ff8c42;            /* warm amber — Friday Labs default */
  --brand-glow: rgba(255, 140, 66, 0.25);

  --up:         #4ade80;            /* green — positive deltas */
  --up-bg:      rgba(74, 222, 128, 0.08);
  --down:       #f87171;            /* red — negative deltas */
  --down-bg:    rgba(248, 113, 113, 0.08);
  --neutral:    #94a3b8;

  --chart-grid: rgba(255, 255, 255, 0.04);
  --chart-axis: rgba(255, 255, 255, 0.2);
}
```

Brand color is overridable per client — the template accepts `brand_color` as a parameter and writes it into `--brand` at render time.

## Typography

- **Sans display + body**: Plus Jakarta Sans (400, 600, 700, 800) — same family Tyler uses across his landing pages. Self-host via Google Fonts data-URL embed at the top of the HTML so the report is fully offline-portable.
- **Mono numerals**: JetBrains Mono (400, 600). Used for ALL numbers, KPIs, dates, deltas, percentages, dollar amounts. Negative letter-spacing -0.5px for the Bloomberg-terminal feel.

Sizes:
- Report title (h1): 32px / 700 / -0.02em tracking
- Section heading (h2): 22px / 700 / -0.01em tracking
- Subsection (h3): 15px / 600
- KPI number: 36px / 800 / mono / -0.04em tracking
- Body: 14px / 400 / line-height 1.6
- Muted/meta: 12px / 400 / `--text-muted`
- Mono labels (Bloomberg-style eyebrows): 11px / 600 / uppercase / 0.1em tracking / `--brand`

## Layout grid

- **Page container**: max-width 1080px, centered, 32px horizontal padding.
- **Vertical rhythm**: 80px between sections, 32px between subsections, 16px between cards within a subsection.
- **Card defaults**: `--surface` background, 1px `--border`, 16px border-radius, 24px internal padding.
- **No multi-column body text** — every section is full-width or splits into 2-4 equal-width cards.

## Section anatomy

Every section starts with:
```html
<div class="eyebrow">
  <span class="dot"></span> SECTION NAME · 11 OBSERVATIONS
</div>
<h2>Section title in sentence case</h2>
<p class="lede">One-sentence framing of what this section answers.</p>
```

The dot+eyebrow combo is the unifying motif — it's the same Bloomberg-pill pattern used in Tyler's landing pages, so the report feels like part of the same product family.

## Chart styling

All charts are **inline SVG generated by `charts.py`** at render time. They do not depend on JS.

### Sparkline (inside KPI tiles)
- 1.5px stroke, `--brand`
- No axes, no grid, no labels
- Soft area-fill below: `--brand` at 8% opacity
- Width: 100% of container, height: 32px
- Last point as a 3px filled circle

### Line chart (main trend)
- Multiple series support (max 4) — `--brand`, plus three muted neutrals (#94a3b8, #64748b, #475569)
- 1.5px stroke, area fill at 8% opacity below the primary series only
- Subtle grid: 4 horizontal lines at `--chart-grid`
- X-axis labels in mono, 11px, `--text-dim`
- Y-axis labels in mono, 11px, `--text-dim`, right-aligned
- Tooltip on hover: not interactive (static SVG) — instead, show min/max/avg as small annotations in the corner

### Bar chart
- Bars in `--brand`, 4px border-radius on top corners
- Spacing: 60% bar, 40% gap
- Numeric labels above each bar in mono 11px
- Optional second series in `--text-muted` for prior-period comparison

### Donut / spend distribution
- 0.6 inner-to-outer ratio (thick ring)
- Brand color + 4 neutrals
- Center label: total in big mono
- Legend below with color square + label + percentage

### Heatmap (best time to post)
- 7x24 grid for day-of-week × hour
- Cell color: linear interpolation from `--surface-2` (low) to `--brand` (high)
- Tooltip not interactive — peak cells get a small dot marker

### KPI tile
- Big number (mono, 36px) + small unit
- Delta pill below: green or red, mono, with arrow
- Sparkline at the bottom, full width

```html
<span class="delta delta--down">↓ 8%</span>
<span class="delta delta--flat">— flat</span>
```

## Insight callout (the "investigator" output)

Distinct visual treatment for the AI-generated observation cards — they need to feel like they're surfaced by a tool, not written by the user.

```html

  <div class="insight__tag">● INSIGHT 03</div>
  <h3 class="insight__title">Your TikTok views tripled but conversions didn't follow.</h3>
  <p class="insight__body">Long-form description with context, mechanism, and recommended action.</p>
  <div class="insight__action">
    <span class="insight__action-label">Recommended action</span>
    <span class="insight__action-text">Test a stronger DM-handoff call-to-action on the top-3 viral videos this week.</span>
```


## Hero card (top of report)

The single most important visual element. Contains:
- Report title + period
- The "headline finding" — one sentence, the single most-important takeaway of the week
- 2-3 supporting top-line metrics

Treated as a glassmorphic card with a soft brand-color glow halo behind it.

## Anti-patterns

- **No emojis** anywhere in the report (the eyebrow dot is a CSS `::before`, not an emoji).
- **No gradient buttons** (CTA is solid `--brand` only, used sparingly).
- **No screenshots of dashboards** — every chart is rendered fresh as inline SVG.
- **No third-party fonts loaded via CDN** at view time — fonts must be inlined or self-hosted.
- **No light-mode toggle** — the report is dark mode only. Operators reviewing on Monday morning don't want a bright white screen.
- **No "Generated by AI" badges** — the analysis is presented as the report's own intelligence, not as ChatGPT output.
