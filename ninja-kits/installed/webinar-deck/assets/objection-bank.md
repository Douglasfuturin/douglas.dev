# Objection Bank

> Every prospect arrives at the close with the same 8-12 objections. They differ slightly by niche but cluster around predictable categories. This file is the menu of objections you must address, directly via bonus design, indirectly via story selection, or finally via the FAQ slide.

## How to use this file

The 150-slide framework addresses objections at three different points:

1. **In Section 5-7 (3 Secrets)**, via mini-story selection (each story disarms a specific objection)
2. **In Section 10 (Stack)**, each bonus is designed to kill one specific objection
3. **In Section 12 (FAQ)**, the leftover 5 objections that didn't get addressed earlier

This file lists the universal objections + the move that handles each one. When building the deck for [CLIENT NAME], cross-reference [CLIENT NAME]'s actual sales-call recordings / support tickets / DM history, the real objections always cluster around 60-70% of this list with 30-40% niche-specific.

## Universal objections

### MONEY

**"I can't afford it."**
- Handle in: Close 1 (Money/ROI slide)
- Move: ROI math + payment plan + cost-of-not-solving
- Stack bonus that helps: payment plan as a separate "bonus" line

**"I don't see the ROI."**
- Handle in: Close 1
- Move: explicit ROI calculation with conservative numbers, let the audience fill in their own multiplier

**"Why is it this expensive?"**
- Handle in: Stack (value buildup) + comparison anchor (vs. alternatives)
- Move: comparison anchor slide 139 makes alternatives look more expensive

**"I've spent money on this before and it didn't work."**
- Handle in: Secret 1 (Vehicle) + mini-story
- Move: case study of someone who tried the wrong vehicle, then this one. Specifically address "why this is different from what failed before"

---

### RISK

**"What if it doesn't work?"**
- Handle in: Close 2 (Risk/Guarantee)
- Move: conditional guarantee, "if you do X and don't get Y, I'll Z"

**"What if I'm the exception?"**
- Handle in: Secret 2 (Internal) + diverse case studies in 3 Secrets sections
- Move: 3-5 case studies across different demographics so SOME of them mirror the prospect

**"What if you're scamming me?"**
- Handle in: Section 2 (Who Am I) + logo wall + screenshots
- Move: proof slides early + brand-name social proof + risk reversal later

---

### CAPABILITY

**"I'm not [smart / young / old / experienced / tech-savvy] enough."**
- Handle in: Secret 2 (Internal Beliefs), this IS the entire Secret 2 section
- Move: mini-story of someone whose limitation matched the prospect's

**"I don't have the time."**
- Handle in: Secret 2 + Stack bonuses (templates, done-for-you elements)
- Move: stack bonus "Done-for-you X, kills the time problem"

**"I'm not creative / disciplined / motivated enough."**
- Handle in: Secret 2 + Stack bonuses (accountability, templates)
- Move: bonus that removes the need for creativity (swipe files) or builds discipline (group accountability)

**"I'll get stuck on the technical parts."**
- Handle in: Stack bonus
- Move: bonus "Step-by-step technical walkthroughs" or "Done-for-you technical setup"

---

### CIRCUMSTANCE

**"My niche / industry / situation is different."**
- Handle in: Secret 3 (External) + niche-specific case study in Stack bonus
- Move: bonus "Niche-specific playbook for [their industry]", or aggregate case studies across many niches

**"The market is saturated."**
- Handle in: Secret 3, this IS a Secret 3 belief
- Move: reframe story, saturation = proof of demand, plus differentiation framework

**"The algorithm / economy / market is broken right now."**
- Handle in: Secret 3
- Move: address the specific external event by name + show case studies during the same period

**"My boss / spouse / partner won't approve."**
- Handle in: FAQ + sometimes a stack bonus
- Move: FAQ answer addressing the specific stakeholder + optional "How to get buy-in from [stakeholder]" mini-resource bonus

---

### TIMING

**"I want to wait."**
- Handle in: Close 3 (Time/Urgency) + Close 1 (Cost of Not Solving)
- Move: cost-of-inaction slide annualized + real urgency reason

**"I'll do it next month / quarter / year."**
- Handle in: Close 1 (Cost of Not) + Close 3 (deadline)
- Move: specific deadline + specific consequences if missed

**"I want to think about it."**
- Handle in: FAQ
- Move: FAQ answer addressing why thinking-about-it almost always becomes never-doing-it

**"I want to research / compare options first."**
- Handle in: Section 5-7 (3 Secrets) + comparison anchor in Section 10
- Move: pre-empt by showing why alternative methods fail before they leave to look

---

### TRUST

**"Will I actually use this?"**
- Handle in: Stack bonus (accountability) + Close 2 (Risk)
- Move: bonus "Weekly group call attendance" + guarantee "if you don't show up to X calls and don't get Y result, refund"

**"What if I don't like the format?"**
- Handle in: Close 2 + FAQ
- Move: format-specific guarantee + FAQ explaining what the format looks like in practice

**"Will I have support if I get stuck?"**
- Handle in: Stack bonus (group support, office hours, Slack/Discord)
- Move: bonus "12 months of group support" with specific response time

**"What about updates / future changes?"**
- Handle in: FAQ + Stack bonus ("Lifetime updates included")

## Niche-specific objection examples

The universal list above gets adapted for each niche. Examples by industry:

### B2B services / Agency clients
- "I'm not the decision maker" → Stack bonus: "Stakeholder buy-in template"
- "Our internal process is too slow for this" → Address in Secret 3 + bonus

### E-commerce / DTC
- "My margins are too thin for this" → Address in ROI math + payment plan
- "My products are seasonal" → Niche-specific case study bonus

### Coaching / Consulting
- "I'm worried about positioning conflict" → FAQ
- "I don't have an audience yet" → Secret 2 + bonus "Audience-from-zero playbook"

### Course creators / Info products
- "The market is saturated" → Secret 3 (THE big one for this niche)
- "I don't have an email list" → Stack bonus

### SaaS / Software
- "Will this integrate with [their stack]?" → FAQ + integration bonus
- "Our security team needs to approve" → FAQ + compliance asset

### Real estate
- "My market is too competitive" → Secret 3 + market-specific case study
- "Interest rates are too high right now" → Secret 3 (timing reframe)

## How to harvest [CLIENT NAME]'s actual objections

Before building the deck, run this exercise:

1. Pull the last 20 sales-call recordings (or DM threads if no sales calls)
2. Listen for the phrase "but..." or "what about...", the prospect's actual objection follows
3. Tally objections, count which ones come up most
4. The top 10 = the objections this deck MUST address

This is the single biggest quality differentiator in webinar building. Generic objection-handling = generic webinar. Specific-to-this-business objection-handling = converting webinar.

Save the result in `assets/examples/{niche}-objections.md` for future deck builds.

## The FAQ slide (slide 149), top 5 selection

Of all the objections in this file, the 5 that DIDN'T get fully addressed earlier in the deck go on the FAQ slide. Typically:

- 1 timing-related ("why not wait")
- 1 capability-related ("I'm not [X] enough", pick the dominant one for the avatar)
- 1 trust-related ("will I get support?")
- 1 niche-specific
- 1 wildcard from the harvested-objections list

Keep each answer to one short line. Long FAQ answers = the audience reads instead of listening to your close.
