# Stack Slide Anatomy

> The single most important visual sequence in the webinar. Slides 126-140 in the composite framework. Builds value cumulatively, line by line, in front of the audience.

## What the stack actually is

A live-built value visualization where every component of the offer gets a $ value, the values accumulate to a total far above the actual price, and then the actual price is revealed. The drama isn't manipulative, it's that you let the audience watch the math, instead of telling them the math.

## Why it works

Three psychological mechanisms:

1. **Anchoring**, the total value sets a high reference point. The actual price feels small relative to the anchor, regardless of absolute amount.
2. **Specificity**, each line item has a discrete value, making the total feel calculated rather than invented.
3. **Cumulative commitment**, by the time the price is revealed, the audience has mentally said "yes" to each line individually. Reversing all those yeses requires more cognitive effort than agreeing to the price.

The stack only works if each line item is real. Inflated values destroy the entire mechanism, buyer's BS detector trips on one bogus line, and the whole stack collapses.

## Anatomy of a stack line

Each line item has three components:

```
[Component name]                                    $[Value]
[One-line description / what it solves]
```

Example:
```
Core training: "Cold DM Mastery"                   $1,997
The 6-module video course that's generated $4.2M for our students
```

```
BONUS #1: First 30 Days Quick-Start Guide         $497
Step-by-step daily checklist, kills "I don't know where to start"
```

```
BONUS #2: Done-For-You DM Scripts                 $1,497
27 proven scripts across 11 industries, kills "I won't know what to say"
```

## Bonuses must solve specific objections

This is the rule. Every bonus answers ONE specific reason someone wouldn't buy.

| Common objection | Bonus that solves it |
|------------------|---------------------|
| "I don't know how to start" | Quick-start guide / first-30-days checklist |
| "What if I get stuck?" | 12 months of group Slack/Discord access |
| "I don't have time to figure out X" | Done-for-you templates for X |
| "Will this work in my niche?" | Niche-specific case study library or playbook |
| "I'm not technical enough" | Step-by-step screen recordings for the technical pieces |
| "I'm not creative enough" | Swipe file / template bank |
| "I won't stay accountable" | Weekly group accountability calls or buddy system |
| "I won't know if I'm doing it right" | Audit / review of first deliverable |
| "My situation is different" | Office hours / 1-on-1 strategy call |
| "What if the market changes?" | Lifetime updates included |

The exercise: list the top 10 objections from past sales calls / DMs / support tickets. Design one bonus per objection. Put each on the stack.

## Stack length

| Offer price | Recommended line count | Total value target |
|-------------|------------------------|---------------------|
| $497-$997 | 5-7 lines | 5-8× the price |
| $997-$2,997 | 7-9 lines | 4-6× the price |
| $2,997-$9,997 | 8-12 lines | 3-5× the price |
| $10k+ | 10-15 lines | 2-4× the price |

**Why total value shrinks as price grows:** at $497, a $5k value anchor is plausible. At $10k, a $50k value anchor strains credibility. Higher-ticket buyers do the math.

## Value pricing

Each line's $ value should be **defensible**, what would it actually cost on the open market?

- Done-for-you template, what does a freelancer charge for it? ($500-$2k range typically)
- Group support, what does similar 1-year group coaching cost? ($1k-$5k range)
- 1-on-1 audit, what does an hour of comparable expertise cost? ($300-$2k)
- Video course content, what do similar courses sell for? ($297-$2k)
- Software / tool access, what's the retail SaaS price × duration?

If you can't defend a line's price under cross-examination, lower it. A defensible $497 is more powerful than an inflated $4,997.

## The slide-by-slide build (composite slides 126-140)

### Slide 126: Frame
"Let me show you what's included..."

### Slide 127: Core thing (1 line visible)
```
[Core program name]                                $X,XXX
```

### Slide 128: + Bonus 1 (2 lines visible)
```
[Core program name]                                $X,XXX
+ BONUS #1: [name]                                 $XXX
```

Note the `+ BONUS` prefix on every bonus line, visually reinforces the additive build.

### Slides 129-133: Continue adding lines

Each slide adds one new line. Existing lines stay. Bonuses can be styled slightly differently from the core (e.g., bonuses get an accent-color "+ BONUS #N" prefix).

### Slide 134: Total value reveal
```
TOTAL VALUE: $XX,XXX
```

Hero typography. Largest text on the entire slide. Hold 5-10 seconds.

### Slides 135-136: Anchor adjustments
- 135: "But you won't pay anywhere close to that..."
- 136: "You won't even pay half of that..."

These are anticipation slides. Each lowers the imagined price the audience is predicting. The actual reveal feels even smaller relative to where their expectations have been led.

### Slide 137: Price reveal
```
Today's price:
$X
```

The actual price, hero typography. The audience's mental anchor is now $XX,XXX from slide 134, the actual price reads as a deal.

### Slide 138: Payment plan (optional)
If payment plan exists: "Or 3 payments of $Y."

### Slide 139: Comparison anchor
Make the price look small by comparing to alternatives:
```
vs. an agency at $5k/month for 12 months = $60,000
vs. doing it yourself for 18 months at $0/hour you can't recover
vs. this: $X. Once.
```

### Slide 140: Bridge to closes
"Worth it? Let me show you why..."

## Common stack mistakes

| Mistake | Why it kills the stack |
|---------|----------------------|
| Inflated line values | Buyers spot one bogus line and reject the entire pile |
| Bonuses with no objection attached | Feels like filler; cumulative effect dilutes |
| Revealing all lines at once | Kills the drama; lose the anchor build |
| Total too high relative to price | If price is $497 and you claim $50k value, you've now made the deal feel suspicious instead of obvious |
| Skipping the comparison anchor | Without alternatives to compare against, the price stands alone |
| Animated dollar-sign visuals / confetti | Reads as 2010s internet marketing; premium audiences cringe |
| Bonus values larger than the core thing | The math breaks, why would the bonus be worth more than the main offer? |

## Modern stack styling

The 2010s aesthetic (bullet points, crossed-out prices, "ACT NOW!" badges, confetti) is dated. The modern stack:

- Black background, white text
- ONE accent color (default `#FF5C28`)
- Clean sans-serif (Helvetica Now, Inter, SF Pro)
- Right-aligned dollar amounts in a separate column
- Subtle dividers between lines (1px white at 20% opacity)
- No icons, no badges, no shadows
- Total line is BIG and bold; bonus lines are normal weight

The drama comes from the build sequence and the typography hierarchy, not from visual ornamentation.

## When NOT to use a stack

Some audiences reject the stack pattern entirely:

- **High-end B2B** ($25k+ enterprise deals), proposals replace stacks
- **Sophisticated audiences** (engineers, finance pros, ex-marketers), pattern recognition is too strong
- **Brand-led businesses** where premium positioning matters more than perceived discount

In those cases, replace the stack with a "what's included" summary slide + a single price + a strong guarantee. Drop the value math entirely, your audience trusts you OR they don't, and stack drama won't move them either way.

The 150-slide framework includes the stack by default. Strip it (replace slides 126-140 with a 5-slide "what's included" sequence) for the audiences above.
